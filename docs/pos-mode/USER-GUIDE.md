# LNDRY POS — user guide (plain words)

POS mode is for running your shop counter from your phone: make bills, take money, send bills and messages, see how the day went.
The bottom bar has six buttons. Every button has a picture **and** a word.

| Button | What it is for |
|---|---|
| **Home** | Today's numbers. Big **Book Order** button. Quick buttons: **WhatsApp**, **Add Customer**, **Add Garment Price**. Tap a number to see exactly those orders. |
| **Order** | All orders in three tabs: **Booked**, **In Process**, **Done**. Tap an order for the next step, **Pay Now**, **View Invoice**, **Mini Invoice**, **Tags**, **Edit**, **Cancel**. |
| **Search** | Type an order number, a customer's name or phone, or a garment tag. **All customers** shows everyone A to Z, with **Call** and **Profile** on every row. |
| **Expense** | **Cash drawer**: open it in the morning with the cash you have, close it at night after counting. **Add Expense** for rent, tea, electricity… |
| **Report** | **Summary**, **Invoices** (list + chart), **Collection** (how customers paid), **Expenses**. Choose Today / Last 7 days / This month / Pick dates. **Share sales file** sends a CSV that opens in Excel. |
| **Setting** | Customers, price list, extra charges and discounts, WhatsApp messages, team, language, switch between Marketplace and POS, log out. |

## A normal day
1. **Expense → Open cash drawer.** Type the cash in the drawer.
2. **Home → Book Order.** Choose the customer, tap garments, check the total (the server works it out), choose how they pay, **Save Order**.
3. **Order →** open the order → move it along (Start Processing → Mark Ready → Deliver). Take money with **Pay Now**.
4. A customer owes money? **Search → All customers →** their name → **To collect** → tap the order → **Pay Now**.
5. Message a customer: **Home → WhatsApp →** choose the customer → choose the message. WhatsApp opens with the words ready; you press Send.
6. Paid for something? **Expense → Add Expense.**
7. Night: **Expense → Close cash drawer.** Type the cash you counted. If it is different, the app says by how much and asks why and who approved. Then look at **Report**.

## Good to know
* Money is always shown exactly as the server worked it out. The app never guesses a total.
* A cancelled expense stays on the list (crossed out) so there is a record, but it is not counted.
* Staff only see what the owner allowed. Expense/Cash needs the "process orders" right; Report needs the "analytics" right.
* The words used in WhatsApp messages are the same ones as in the counter software. To change them, change them there.
* English, हिन्दी and Hinglish: **Setting → Language**.
